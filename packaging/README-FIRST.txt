STONEVEIL WINDOWS PLAYTEST
==========================

1. Right-click STONEVEIL-Windows-Playtest.zip and choose Extract All.
2. Open the extracted folder.
3. Run stoneveil.exe from that folder.

Do not run stoneveil.exe from inside the ZIP and do not copy the EXE out by
itself. The content folder must remain beside stoneveil.exe; it contains the
levels, textures, audio, character catalog, and campaign data.

If the game reports GAME CONTENT NOT FOUND, close it, extract the complete ZIP,
and launch the copy in the extracted folder.
